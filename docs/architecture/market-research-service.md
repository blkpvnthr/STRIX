# Autonomous market-research service

STRIX now includes a narrow, deterministic daily-bar research slice. It is a
research and decision-support system only: there is no broker connector, order
model, or real-money execution capability.

## Implemented flow

`mandate → immutable CSV snapshot → bounded hypotheses → immutable experiment spec → chronological holdout → costs → falsification → classification → immutable run → offline replay`

The initial feature families are momentum, reversal, and volatility. Every
campaign has fixed hypothesis/parameter/time budgets. Final-holdout exposure is
recorded on the experiment specification. Classification distinguishes web-job
completion from `VERIFIED_RESEARCH_EDGE`.

The durable service registry uses an atomically replaced JSON registry and the
existing immutable `RunStore`. On restart, interrupted jobs return to `QUEUED`.
Concurrency is bounded. The internal API trusts identity headers only when the
request carries `STRIX_INTERNAL_TOKEN`; BLKPVNTHR.OS validates the user session
and derives tenant/user/role before setting those headers.

## Actual data support

- Versioned offline CSV daily bars with adjusted close and volume.
- Synthetic development fixture generated by `strix-demo-fixture`.
- Existing SEC EDGAR Company Facts remain supported by the original STRIX CLI.

Not implemented: licensed production price feed, historical constituent
membership, delisted securities, dividend-event decomposition, or paper
trading. The development fixture cannot establish a real market edge.

## Development

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/strix-demo-fixture
STRIX_INTERNAL_TOKEN=development-only-change-me \
STRIX_RESEARCH_ENABLED=true \
STRIX_RESEARCH_SCHEDULER_ENABLED=false \
STRIX_OFFLINE_DATASET=fixtures/daily-bars.csv \
.venv/bin/strix-service
```

The service binds to `127.0.0.1:8765` by default. Do not expose it directly to
browsers. Production scheduling remains disabled until explicit owner approval.
