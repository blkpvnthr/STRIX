# STRIX v0.2.0 — Release Notes

**Evidence-verified OpenAI research agent + web application.** Release candidate
on the `STRIX` branch — audited and ready for review; not yet merged to `main`.

## Highlights

- Ask natural-language questions about markets, securities, and the economy and
  get answers where **every quantitative claim is independently recomputed** from
  preserved observations before it is shown. The model proposes; a separate
  verifier it cannot influence decides.
- Two interfaces over **one shared engine**: the `strix ask` CLI and a dark-first
  React web app (conversational research, inline citations, evidence inspector,
  verification verdicts, source timestamps, history, follow-ups, cancellation).
- Deterministic, replayable runs: `strix replay RUN-...` re-verifies a run with no
  model and no network.

## Model & cost

Default model **GPT-6 Luna** (`gpt-6-luna`) — cheapest permitted
($0.10/$0.01/$0.50 per 1M in/cached/out). Per-run budget enforced in code
(`STRIX_AGENT_MAX_COST_USD`, default $0.05). The eight demonstration questions
cost **~$0.012 total**.

## Startup

```bash
python -m pip install -e ".[dev,web]"
python -m strix.agent.diagnostics        # live connectivity check (redacted)
strix ask "What is the recent realized volatility of SPY?"
( cd web && npm install && npm run build )
strix-web                                # http://127.0.0.1:8000  (API + UI)
```

## Verification & benchmark

All eight demonstration runs replay PASS; of all claims presented as verified,
zero were false positives. Answer coverage (50%) is reported separately from
verification correctness (100%) — insufficient-evidence answers do not count as
answered. See `v0.2.0-benchmark.md` and the audit in `v0.2.0-audit.md`.

## Known limitations

- No FRED/BLS/Treasury connectors — inflation and yield questions return honest
  insufficient-evidence results rather than fabricated numbers.
- The agent verifier has no SEC financial-ratio calculators (e.g. operating
  margin); such claims remain unresolved.
- Coverage varies run to run (model non-determinism); correctness does not.
- The local web API has **no authentication** (binds `127.0.0.1`, localhost-only
  CORS). Do not expose the port. A shared-token option is planned for v0.3.0.
- No investment advice; no trading; the DEMO fixture is synthetic.

## Security summary

Key held as `SecretStr`, never logged/persisted/committed or sent to the browser;
`.env` gitignored. Retrieved content treated as untrusted data; the independent
verifier makes prompt injection unable to grant verification. See `v0.2.0-audit.md`
§8.
