# STRIX v0.2.0 — Research Benchmark

Live run of the eight mandatory demonstration questions through the completed
pipeline (gpt-6-luna + Alpaca), 2026-11-22. **Answer coverage and verification
correctness are measured separately. An insufficient-evidence (or unresolved-
only) response is NOT a successfully answered question.**

## Metric definitions

- **Answered (coverage):** the run produced ≥1 **independently verified** finding.
- **Insufficient / unresolved:** 0 verified findings — honest non-answer, *not*
  counted as answered.
- **Verification correctness:** of all claims presented as verified, how many are
  actually correct — measured by independent recomputation and deterministic
  replay. A false positive is a claim shown as verified that replay/recompute does
  not reproduce.

## Summary

- **Answer coverage: 4/8 (50%)** — Q1, Q2, Q3, Q7.
- **Not answered: 4/8** — Q4/Q5/Q8 insufficient evidence; Q6 unresolved only.
- **Verification correctness: 10/10 verified claims correct (0 false positives).**
  Every claim presented as verified was independently recomputed; **all 8 runs
  replay PASS**.
- **Total cost: $0.0115** for all eight (~$0.0014 average; well under the
  $0.05/run budget).

## Why the non-answers are non-answers (honest, by design)

- **Inflation / Treasury (Q4, Q5):** no FRED/BLS/Treasury connector is configured;
  values seen only in web search are attribution-only without a retrievable
  primary source, so they are reported as insufficient rather than fabricated.
- **Apple operating margin (Q6):** the agent's verifier has no operating-margin
  *ratio* calculator (only the v1 pipeline does), so a margin claim stays
  unresolved. Revenue/operating-income growth *are* verifiable.
- **Sectors (Q8):** the capability exists (fetch sector ETFs → relative
  performance), but gpt-6-luna did not pursue it on this pass.

## Caveat: model non-determinism

The verified-count per question varies run to run (e.g. Q1 produced 2 verified
findings on an earlier pass and 6 here) because the model chooses how many series
to fetch. **Verification correctness does not vary**: whatever the model proposes,
only claims the verifier independently reproduces are shown as verified. v0.3.0's
deterministic research planner will make coverage stable and repeatable.
